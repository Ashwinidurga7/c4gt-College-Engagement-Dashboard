## C4GT UI update — September 2026

This update keeps the existing C4GT structure and adds:
- Two-step role selection on login so only the selected role's login form is shown.
- Student portfolio landing page with Attendance, Activities, Internships/Participation, Resume, Achievements and Analytics.
- Student Resume editor with live preview and browser-local persistence.
- Student attendance view and Faculty attendance management with shared browser-local attendance data.
- Admin Overall Campus view for KIET, KIET+ (KIET II), and KIEW plus C4GT Hub, Global Coding Club, Hackathons, Smart City Lab, Robotics Lab and Toastmasters.
- Official KIET Group website imagery reused for campus/community cards.
- Additive styling so the previous pages and backup components remain in the project.
